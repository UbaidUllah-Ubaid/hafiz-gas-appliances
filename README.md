# Hafiz Gas Appliances

E-commerce application containing a separate Angular frontend and Node.js backend.

## Project folders

- [`ecommerce-frontend/`](./ecommerce-frontend/) — Angular web application.
- [`ecommerce-backend/`](./ecommerce-backend/) — Express API with SQLite.

Each folder has its own README with setup and run instructions. Start the backend before using frontend features that call the API.

## Repository safety

Local environment files, dependencies, build output, the SQLite database, and uploaded product images are excluded by `.gitignore`. Keep a separate backup of your local database and uploads.
